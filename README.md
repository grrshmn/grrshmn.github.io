# Ксения — веб-дизайнер

Сайт-резюме и портфолио: обо мне, работы, услуги и цены, этапы работы, навыки и контакты.

**Сайт:** https://grrshmn.github.io/

## Как обновить

- **Контакты** — массив `CONTACTS` в конце `index.html`. Пустые строки на сайте не показываются.
- **Фото** — положите `assets/photo.jpg` и раскомментируйте строку с `<img>` в блоке `.avatar`.
- **Новая работа** — скопируйте блок `<article class="case">` в разделе «Работы».

Чистые HTML и CSS, без сборки. Шрифты: Cormorant Garamond и Manrope (Google Fonts).
